# She Coders – ABTalks2.0

A modern, student-focused redesign of the ABTalks 60-Day Coding Challenge platform, designed to make daily coding progress easier to track, understand, and maintain.

## 🚀 Live Demo

**Live Website:** https://abtalks20.vercel.app/

## 📌 Project Overview

The ABTalks 60-Day Coding Challenge helps students build consistent coding habits through daily coding tasks and progress tracking.

Our redesign focuses on creating a clean, engaging, and student-friendly experience where users can easily:

* Track their daily coding progress
* Monitor their coding streak
* View challenge completion status
* Submit proof of their coding work
* Track overall performance
* Access the platform easily across devices

## 🎯 Hackathon Goal

The goal of this project is to reimagine the ABTalks 60-Day Coding Challenge with a cleaner, more engaging, and student-friendly interface.

The redesign aims to encourage consistency, make progress visible, and provide students with a simple way to manage and showcase their daily coding journey.

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/fathima-saniya/SheCoders-ABTalks2.0
```

### 2. Navigate into the project

```bash
cd SheCoders-ABTalks2.0
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local development URL displayed in your terminal.
