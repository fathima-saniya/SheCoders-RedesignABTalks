# She Coders – Redesign ABTalks

A modern, student-focused redesign of the ABTalks 60-Day Coding Challenge platform, built to make daily coding progress easier to track, understand, and maintain.

## 🚀 Live Demo

[View Live Website] https://abtalks20.vercel.app/

## 📌 Project Overview

The ABTalks 60-Day Challenge helps students build consistent coding habits through daily tasks.

Our redesign focuses on:
- Clear daily challenge tracking
- Streak and progress visibility
- Student performance insights
- Easy submission of proof of work
- Mobile-friendly and responsive UI
- Simple and engaging student experience

## ✨ Key Features

### 🏠 Landing Page
- Introduction to the 60-Day Challenge
- Clear call-to-action
- Challenge highlights

### 📊 Student Dashboard
- Current streak
- Today's task
- Overall progress
- Completion percentage
- Student standing

### 📝 Challenge Day
- View the day's coding task
- Submit GitHub commit proof
- Submit LinkedIn post proof
- Track challenge completion
